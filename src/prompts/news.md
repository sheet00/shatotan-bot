# ニュース投稿のタスク設定

## タスク

以下の記事本文を読んで、Xに投稿する短い感想を書いてください。

## 文章の条件

- 本文に具体的に書かれていることに触れてください。
- 日本語40〜100文字程度で、自然な感想を書いてください。
- タイトルとURLを含めてXの文字数制限に収めるため、感想は重み付き文字数で{{commentLimit}}以内にしてください。日本語の文字と絵文字は原則2、半角英数字は原則1として数えます。この上限を優先し、必要なら40文字未満にしてください。
- URL、ハッシュタグ、メンションは不要です。記事URLはBOTが付けます。
- 投稿文は「感想 → [記事タイトル] → 記事URL」の順に改行して並べます。記事タイトルは必ず元のタイトルを角括弧`[]`で囲み、BOTが付けます。`comment`には感想だけを書いてください。
- 感想の根拠となる本文の短い一節を、そのまま`evidence`に入れてください（12文字以上）。

## 出力形式

返答は次の形式のJSONのみとし、説明やコードフェンスは付けないでください。

```json
{ "comment": "感想", "evidence": "本文からの短い一節" }
```

## 記事データ

以下はJSON形式の引用データです。

{{article}}
