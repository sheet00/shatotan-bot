# 天気予報投稿のタスク設定

## タスク

以下の気象概況と明日の天気予報データを読んで、Xに投稿する明日の天気についてのポストを作成してください。

## 大切にすること：行動変化を気づかせる実用的なアドバイス

単に「明日は晴れです」といった1行の事実報告で終わらせず、読む人が**「明日どんな行動をとるべきか（服選び、持ち物、体調管理）」に気づいて行動を変えられる具体的な生活ヒント**を必ず盛り込んでください。

- **持ち物（傘の判断）**：雨や雪、降水確率に応じて「折りたたみ傘持っていこう」「傘いらずで身軽にお出かけできそう」など具体的に伝える。
- **服装（気温・寒暖差）**：最高気温・最低気温や昼夜の寒暖差に合わせ、「昼は半袖でも夜はヒンヤリするからカーディガン必須」「脱ぎ着しやすい上着があると調節しやすいよ」など、明日の準備に直結するアドバイスを入れる。
- **生活・体調**：乾燥、紫外線、朝晩の冷え込み、洗濯物の外干しなど、気象データや概況に触れられている注意点を行動のヒントにする。

## 文章の条件

- 明日の天気・気温・寒暖差に触れつつ、上記のような「読んだ人がするべき具体的な行動」を友達に話しかけるような感覚で自然に添えてください。
- 日本語80〜140文字程度で、2〜3文でテンポよく親しみやすい自然な口語で書いてください。
- Xの文字数制限に収めるため、発言内容は重み付き文字数で{{commentLimit}}以内にしてください。日本語の文字と絵文字は原則2、半角英数字は原則1として数えます。
- URL、リンク、ハッシュタグ、メンションは一切入れないでください。発言内容のテキストのみを出力してください。
- `comment`には発言内容だけを書いてください。
- 予報データや概況にない事実や数値を勝手に創作しないでください。

## 出力形式

返答は次の形式のJSONのみとし、説明やコードフェンスは付けないでください。

```json
{ "comment": "発言内容" }
```
